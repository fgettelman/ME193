Navigator (behavior cloning)

k-nearest neighbours from the navigator's state (distance, heading, turns made, dead-reckoned position, stairs) to the instruction. Trained on every reviewed walk marked "use", from both partners, at most 10.

Stairs classifier

Built on the step counter: one prediction per stride from how far the thigh swings, how much it jolts for its speed, and how long it swings back. None of these depend on how fast you walk. Record 20-30 s per recording, 2-3 of each kind at different paces. Stand still 2 s before you start. These recordings don't count as walks.
